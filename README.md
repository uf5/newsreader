# Newsreader

![drawing](./assets/icon_sqr.svg)

Newsreader is a u**n**iv**e**rsal **w**eb**s**ite **reader** and lisp interpreter.

The main feature of the program is the ability to read any website. This is achieved using a custom Scheme language dialect interpreter, written from scratch, which allows the user to configure the program to read any website using custom scripts.
